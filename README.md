## 🌸 Project: Iris Flower Classification

### 📌 Objective
The goal of this project is to build a robust machine learning classification model that can accurately identify and classify Iris flower species (Setosa, Versicolor, and Virginica) based on their sepal and petal measurements.

---

## 🛠️ Technologies Used
* **Python** (Core programming language)
* **Pandas & NumPy** (Data manipulation and preprocessing)
* **Scikit-Learn** (Machine learning model implementation and evaluation)

---

## 📊 Dataset & Methodology
* **Dataset Source:** Standard Iris Flower Dataset (processed using exact feature parameters matching standard data criteria).
* **Features Used:** 
  * Sepal Length (cm)
  * Sepal Width (cm)
  * Petal Length (cm)
  * Petal Width (cm)
* **Target Variable:** Species (`setosa`, `versicolor`, `virginica`)
* **Algorithm:** **Random Forest Classifier** (An ensemble learning method chosen for its high accuracy and resistance to overfitting).
* **Train-Test Split:** 80% Training data, 20% Testing data.

---

## 📈 Performance & Results
* **Model Accuracy:** **100.00%**
* **Classification Report Metrics:**
  * Achieved perfect precision, recall, and f1-score across all three flower species classes.

---

2. Run the cells sequentially to load the dataset, train the model, and evaluate the performance.
