# CodeAlpha Data Science Internship Tasks

This repository contains the machine learning and data science tasks completed as part of the **CodeAlpha Data Science Internship**.

## 🛠️ Technologies Used
* Python
* Pandas, NumPy
* Scikit-Learn

---

## 📂 Project List

### 1. Iris Flower Classification (`iris_classification.ipynb`)
* **Objective:** Build a machine learning model to classify iris flowers into three species based on their sepal and petal measurements.
* **Algorithm:** Random Forest Classifier
* **Performance:** 100.00% Accuracy

### 2. Car Price Prediction (`car_price_prediction.ipynb`)
* **Objective:** Predict the market price of cars based on features like horsepower, mileage, and age.
* **Algorithm:** Linear Regression
* **Performance:** Evaluated using R-squared score.
